duong_gia_huy API

REST API cho app Flutter điểm danh sinh viên · Node.js + Express + MongoDB Atlas · deploy Render · nhóm 4 con tuất
GET /health → đang kiểm tra…

Base URL: · Dữ liệu JSON · Xác thực: Authorization: Bearer <JWT> · Lỗi: {"message": "..."}

Xác thực

POST/auth/registerĐăng ký bằng email → gửi OTPcông khai
POST/auth/register/verifyXác minh OTP đăng ký → JWTcông khai
POST/auth/loginTên đăng nhập + mật khẩu → gửi Email OTPcông khai
POST/auth/login/verifyXác minh OTP đăng nhập → JWTcông khai
POST/auth/googleĐăng nhập Google OAuth 2.0 (xác thực idToken) → JWTcông khai
POST/auth/faceĐăng nhập bằng khuôn mặt (vector FaceNet-512) → JWTcông khai
GET/meThông tin tài khoản đang đăng nhậpđã đăng nhập
PUT/me/face · DELETE /me/faceBật / tắt đăng nhập bằng khuôn mặtđã đăng nhập

Quản trị (CRUD)

GET/admin/usersDanh sách tài khoản (lọc vai trò, tìm kiếm) · POST tạo · PATCH /:id sửa · DELETE /:id xoáadmin
GET/admin/subjectsMôn học · POST · PATCH /:id · DELETE /:idadmin
POST/admin/classesLớp học phần + thời khoá biểu · PATCH /:id · DELETE /:idadmin
POST/admin/classes/:id/studentsGhi danh sinh viên · DELETE /:id/students/:sidadmin
POST/admin/importNhập file Excel thời khoá biểu + danh sách SV (file mẫu)admin

Lớp học, buổi học, điểm danh

GET/classes · /classes/:idLớp học phần (tự lọc theo vai trò)đã đăng nhập
GET/me/todayLịch học hôm nay theo thời khoá biểuGV, SV
POST/classes/:id/sessionsMở buổi điểm danh (ngoài giờ TKB → buổi bù) · GET danh sách buổiGV
PATCH/sessions/:idSửa, đóng / mở buổi, ghim vị trí GV · GET chi tiết · DELETE xoáGV
PATCH/sessions/:id/records/:sidĐổi trạng thái điểm danh 1 SVGV
GET/sessions/:id/qrMã QR động ký HMAC, đổi mỗi 60 giâyGV
POST/checkinQuét QR + GPS (bán kính 100 m, chặn GPS giả)SV
GET/me/attendanceLịch sử chuyên cần, số buổi còn được vắngSV

POST/spot-checks/respondXác minh bằng khuôn mặt + GPSSV
